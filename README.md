# منصة نِعْمَة (Nemaa) — تَذَكَّرْ لِتَشْكُرْ 🌿

منصة ويب روحية وتدبرية متكاملة باللغة العربية، مصممة لاستشعار نعم الله الباطنة والظاهرة وتدبرها عبر بطاقات تفاعلية أنيقة وتأملات ملهمة، لترسيخ الحمد والامتنان اليومي.

---

## 🎨 الهوية البصرية والتصميم (UI/UX)
- **فلسفة التصميم**: واجهة هادئة، روحية، وبسيطة (Minimalist & Spiritual) مستوحاة من المخطوطات والزخارف الإسلامية المعاصرة.
- **لوحة الألوان المعتمدة**:
  - خلفية كريمية رملية دافئة: `#FDFBF7`
  - أخضر زيتي عميق: `#2C4A3E`
  - لمسات ذهبية / عنبرية: `#D4AF37`
  - نصوص فحمية واضحة ومريحة للقراءة: `#2D3748`
  - وضع سكينة الليل (Dark Mode) المخصص للتأمل المسائي الهادئ.
- **الخطوط العربية (Google Fonts)**:
  - العناوين والتأملات: **Reem Kufi** و **Amiri**
  - عناصر واجهة المستخدم: **Cairo** و **Tajawal**

## ✨ المميزات والخصائص التفاعلية

### 1. مولد النعم الذكي والتصنيفات (Blessing Generator)
- **عرض عشوائي سلس**: زر بارز «نِعْمَةٌ جَدِيدَةٌ» مع تأثيرات تنقل انسيابية ومفاتيح اختصار (زر المسافة Spacebar أو الأسهم).
- **تصنيفات رئيسية متكاملة مع عدادات حية**:
  - 🌿 **نعم باطنة وخفية**: كستر الذنوب، لطف المقادير، نعمة النسيان للآلام، وانصراف الشر دون علمك.
  - 🩺 **الصحة والجسد**: العافية بلا تنبيه، نبض القلب، نعمة البصر، المفاصل وجهاز المناعة.
  - 🕌 **نعم إيمانية وروحية**: الهداية للإسلام، حلاوة السجود، مواساة القرآن، والراحة في الصلاة.
  - 👨‍👩‍👧‍👦 **العلاقات والأهل**: دعاء الوالدين، البيت الآمن، الصديق الصالح، والكلمة الطيبة.
  - ☀️ **نعم يومية بسيطة**: رشفة الماء البارد، قوت اليوم، الأمان في السرب، ورائحة المطر.
- **شواهد موثقة**: كل نعمة مرفقة بآية قرآنية أو حديث نبوي شريف مع التخريج والسورة ورقم الآية.

### 2. تفاعلات الحمد والامتنان (Gratitude Interactions)
- **زر «الْحَمْدُ لِلَّهِ» التفاعلي**:
  - انبعاث جزيئات ذهبية وخضراء (Confetti Particles).
  - نغمة رنين روحية هادئة مبرمجة عبر **Web Audio API**.
  - ظهور عبارات حمد وتسبيح مهدئة للقلب (مثل: *«لَئِن شَكَرْتُمْ لَأَزِيدَنَّكُمْ»*, *«بالشكر تدوم النعم»*).
- **عداد الحمد اليومي وتتبع الاستمرارية (Streak Tracker)**:
  - حساب عدد مرات الحمد والتأمل يومياً وحفظها تلقائياً.
  - شارات تقديرية للأوراد والحمد المستمر (*شاكر*، *ذاكر*، *حامدٌ وممتن*).

### 3. المشاركة والتحميل كصورة مصممة (Social & Sharing)
- **تحميل البطاقة كصورة**: توليد صورة عالية الدقة (1080×1350) بضغطة زر واحدة صالحة للمشاركة الفورية على حالات واتساب وإنستغرام، متضمنة الشعار والنص والآية.
- **روابط مشاركة سريعة**: مشاركة مباشرة عبر واتساب، تيليجرام، منصة إكس (Twitter)، مع نسخ النص بضغطة زر.

### 4. التخصيص والمفضلة والتدوين الخاص
- **المفضلة (Bookmarks)**: إمكانية حفظ النعم المفضلة في قائمة محلية والرجوع إليها أو تصفيتها في أي وقت.
- **إضافة نعمة خاصة (Personal Blessings)**: نموذج يتيح لك كتابة نعم وتدبرات من حياتك الشخصية وإدراجها فوراً في دورة النعم وظهورها بوسم *«نعمة خاصة بك»*.
- **بحث وتصفح شامل**: نافذة بحث فورية عن أي كلمة، معنى، أو وسم بين جميع النعم.

### 5. مؤثرات صوتية وبيئية للسكينة (Ambient Soundscape)
- مولد أصوات طبيعية وروحية خفية مدمج يعمل بدون إنترنت (Offline Procedural Web Audio):
  - 🌧️ مطر هادئ (Light Rain)
  - 🍃 نسيم عليل وسكينة (Gentle Breeze)
  - 🐦 تغريد فجر خافت (Dawn Birds)
  - 🕊️ سكون وتأمل بتردد 432Hz

## 🚀 التشغيل والتطوير المحلي

1. **تثبيت الحزم**:
   ```bash
   npm install
   ```
2. **بدء خادم التطوير**:
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:5173`

3. **بناء النسخة الإنتاجية**:
   ```bash
   npm run build
   ```

## 🌐 النشر والاستضافة (Deployment)
المشروع عبارة عن تطبيق React حديث مبني بواسطة Vite، ويمكن نشره مباشرة بضغطة زر على:
- **Vercel**: قم بربط المستودع وسيقوم باكتشاف إعدادات Vite تلقائياً.
- **Netlify**: أمر البناء `npm run build` ومجلد النشر `dist`.
- **GitHub Pages** أو أي استضافة سحابية ثابتة.
